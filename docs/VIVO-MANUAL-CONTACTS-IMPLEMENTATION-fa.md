# قابلیت مخاطبان دستی VIVO

این تغییر، مخاطبان را از دنبال‌کردن شبکه اجتماعی جدا می‌کند و افزودن مخاطب را به اقدام آگاهانه کاربر بر اساس نام کاربری دقیق محدود می‌سازد.

## مسیرهای API

| متد | مسیر | کاربرد |
|---|---|---|
| GET | `/contacts/search?username=...` | جست‌وجوی نام کاربری دقیق و بازگرداندن وضعیت رابطه |
| POST | `/contacts/request` | ارسال درخواست؛ اگر درخواست معکوس در انتظار باشد، رابطه را می‌پذیرد |
| GET | `/contacts/requests` | فهرست درخواست‌های دریافتی و ارسالی |
| POST | `/contacts/respond` | پذیرش یا رد درخواست دریافتی با `requestId` و `action` |
| GET | `/contacts/list` | فهرست مخاطبان پذیرفته‌شده |
| POST | `/contacts/remove` | حذف رابطه مخاطب پذیرفته‌شده با `userId` |

## قواعد حریم خصوصی

- جست‌وجوی مخاطب فقط با نام کاربری VIVO انجام می‌شود.
- جست‌وجو از شماره تلفن، ایمیل یا دفترچه تلفن دستگاه استفاده نمی‌کند.
- پاسخ جست‌وجو فقط اطلاعات عمومی/پروفایلی لازم را برمی‌گرداند و تلفن یا ایمیل را شامل نمی‌شود.
- درخواست‌های مسدودشده قابل ارسال یا مشاهده نیستند.
- شروع گفت‌وگوی خصوصی جدید به پذیرفته‌شدن درخواست ارتباط نیاز دارد.
- رابطه مخاطب مستقل از دنبال‌کردن پست‌هاست.

## آزمون پذیرش لازم

۱. حساب A نام کاربری دقیق حساب B را جست‌وجو کند؛ هیچ شماره یا ایمیلی نباید برگردد.
۲. A درخواست ارتباط بفرستد؛ B باید اعلان/درخواست دریافتی ببیند.
۳. B درخواست را رد کند؛ A و B نباید مخاطب پذیرفته‌شده شوند و ساخت گفت‌وگوی خصوصی باید رد شود.
۴. A درخواست جدید بفرستد و B بپذیرد؛ هر دو باید در فهرست مخاطبان همدیگر قرار بگیرند.
۵. A از پروفایل یا فهرست مخاطبان، گفت‌وگو را باز کند؛ همان گفت‌وگوی خصوصی مشترک باید بازگردد.
۶. حذف مخاطب باید رابطه را حذف کند؛ ساخت گفت‌وگوی جدید پس از حذف باید رد شود.
۷. دو حساب مسدودکننده یکدیگر نباید بتوانند جست‌وجو، درخواست یا گفت‌وگوی تازه برقرار کنند.
۸. کاربر ناشناس و نشست نامعتبر نباید به هیچ‌یک از مسیرهای مخاطبان دسترسی داشته باشند.
